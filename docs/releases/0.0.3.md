# 0.0.3（尚未發布）

本版支援 **Python 3.10**，執行期**只依賴 NumPy**，並再加快大量箱形圖的建立。

## Python 3.10 與只依賴 NumPy

- `requires-python` 改為 `>=3.10`，相依只剩 `numpy>=1.25`；發布流程新增 cp310 wheel。
  唯一用到 3.11 語法的 `BaseException.add_note` 改為相容寫法。
- cycler 0.12.1、pyparsing 3.3.3、python-dateutil 3.0.0、six 1.17.0 原樣內建於
  `matplotlib_rs._vendor`，`tools/vendor_deps.py` 可從固定版本重現，CI 檢查內容一致。
  已安裝的 cycler 仍優先使用，使 `cycler.Cycler` 物件可通過驗證；
  `matplotlib_rs.install()` 後，未安裝的 `cycler`／`dateutil` 也可被腳本匯入。
- constrained layout：以 Rust 移植 kiwi 1.5 的 Cassowary 求解器（`src/mpl/kiwi.rs`），
  Python 端依 kiwisolver 的 `symbolics.h` 逐一重現運算（例如除法乘上 `1.0 / d`）。
  kiwisolver 依變數的記憶體位址排列限制式的項，僅改變輸出路徑長度就可能改變 SVG 座標末位；
  內建版本依建立順序排列，結果固定。常見版面的座標與 kiwisolver 逐位元相同。
  `MPLRS_KIWI=kiwisolver` 可改用已安裝的 kiwisolver。
- 等高線：以 Rust 移植 ContourPy 的 `mpl2014`（Matplotlib 預設演算法），頂點與路徑碼逐位元相同。
  `serial`／`threaded`／`mpl2005` 仍需 ContourPy；`MPLRS_CONTOUR=contourpy` 可改用 ContourPy。
- Delaunay 三角網格：內建並以 `cc` 編譯 Matplotlib 使用的 qhull 8.0.2（套用 Matplotlib 的 qhull 修補），
  依 Matplotlib `_qhull_wrapper.cpp` 的步驟輸出，三角形、頂點與鄰接順序相同。
  先前沒有 Matplotlib 時改用的 Rust Delaunay 三角形相同但順序不同，`tri_plots` 因此有像素差異；
  現在一律使用 qhull，也不再載入已安裝 Matplotlib 的編譯模組。`MPLRS_QHULL=rust` 仍可選用舊方法。
  從原始碼安裝需要 C 編譯器。
- PNG：沒有 Pillow 時由 Rust 解碼與編碼。`imread` 依 Matplotlib 以 Pillow 讀取的規則轉換
  （1／2／4／8／16 bit 灰階、調色盤與 tRNS、灰階加透明、16 bit 彩色取高位元組），數值相同。
  PDF／SVG／PGF 內嵌影像改由本專案編碼，像素相同但位元組不同；安裝 Pillow 時仍使用 Pillow。
- fontTools 只在 Type 42 字型嵌入時匯入；JPEG／TIFF／WebP／GIF／AVIF、`pil_kwargs` 與
  `PillowWriter` 需要 Pillow，缺少時的 `ImportError` 會說明需要的套件。
  選用套件可用 `pip install "matplotlib-rs[full]"` 安裝。

## 大量箱形圖

每個 `bxp` 呼叫若統計值為一般浮點數，就一次建立全部箱形圖 artists：

- 以 NumPy 逐元素計算與原迴圈相同的座標（保留 `get_xdata()` 的 dtype），
  每種元件一次複製全部 Rust handle（`copy_many`／`copy_many_ragged`／`copy_many_paths`），
  再由 Rust 建立各自獨立屬性字典的 Python 物件，子物件與資料範圍各更新一次。
- callback registry 改在首次使用時建立；箱形圖建立期間暫停循環垃圾回收，
  避免數萬個新物件反覆觸發完整回收。
- 統計的離群值改為整批計算，`merge_kw_rc` 只讀取 `boxplot.*` 設定。

每個 artist 仍是獨立的 `Line2D`／`PathPatch` 與 Rust handle，回傳型別、標籤、
子物件順序、修改、刪除與 pickle 行為不變；統計值非一般浮點數時沿用逐箱路徑。

## 測試

- 新增 `tests/unit/test_native_ports.py`：kiwi、mpl2014、qhull、PNG 讀寫分別逐位元比較
  kiwisolver、ContourPy、Matplotlib `_qhull` 與 Pillow（未安裝時略過比較，只做自我檢查）。
- 新增 `tests/unit/test_numpy_only.py`：不含 site-packages、只有 NumPy 的子行程不得載入其他套件，
  缺少選用套件時的錯誤訊息正確，且四種格式輸出與完整環境相同。
- `test_boxplot.py` 新增 8 組選項（浮點位置、凹口水平、平均值、無 caps、無離群值、逐箱寬度等），
  比較每個元件的 dtype、資料與子物件順序，並測試 `bxp` 的整數／float32 統計值與物件獨立性。
- `tests/compare` 新增 `COMPARE_MPL_PYTHON`／`COMPARE_RS_PYTHON` 跨直譯器比較，
  以及 `COMPARE_DECODE_IMAGES=1` 的內嵌影像解碼比較（其他內容仍須逐位元組相同）。
- CI 新增 Python 3.10 只有 NumPy 的工作，並以 NumPy 1.25.2 重跑 `test_numpy_only.py`。

本機結果：CPython 3.11／3.12／3.13 的 Rust 5 個測試、全部單元與底層差異測試通過，
58／58 案例 PNG／SVG／PDF／EPS 完全一致；CPython 3.10 只有 NumPy 對 Matplotlib 3.11.2 為 58／58，
其中 9 個案例的 SVG／PDF 內嵌影像編碼不同、解碼後像素相同。
cp310 wheel 與 sdist 在乾淨 Python 3.10 venv 安裝後只有 matplotlib-rs 與 NumPy。
