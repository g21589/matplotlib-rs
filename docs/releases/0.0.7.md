# 0.0.7

本版整合 PR #5 的 Rust 執行緒池、共享頂點與 Python 圖例及文字版面配置優化，降低重複運算與記憶體用量。執行期仍只依賴 NumPy。

```bash
python -m pip install matplotlib-rs==0.0.7
```

## 更新內容

- Rust 平行運算重用常駐執行緒池，處理巢狀呼叫、並行呼叫、fork 與 panic；所有平行迴圈統一遵循 `MPLRS_THREADS` 設定。
- Agg path collection 依畫布分帶平行混色，維持繪製順序；線段與路徑共用頂點，減少複製。
- 圖例位置與邊界、文字版面配置及裁切座標轉換減少重複運算；圖例邊界快取由各執行緒獨立保存。
- Gaussian KDE 重用中間計算，加速 violinplot 建圖。
- 保留系統記憶體配置器；新增快速路徑、執行緒池、圖例及相容性測試與量測紀錄。

## 相容性與效能

- 支援 Python 3.10 以上，預編譯 wheel 涵蓋 Linux x86_64、CPython 3.10–3.13。
- 已提交的本機量測中，四個預設位置圖例的 PNG 存檔時間較 0.0.6 約快 2.1 倍；百萬點折線繪製約快 1.6 倍，最高 RSS 由 202 降至 155 MiB。結果依硬體與工作負載而異。
- 量測方法、逐輪資料、像素比對與限制見 [效能報告](../benchmarks/threads-legends-lines.md)。
- 套件發行版本為 `0.0.7`；`matplotlib_rs.__version__` 保留 Matplotlib 相容性 API 版本 `3.11.2`。

發布流程會檢查版本一致性、完整 CI、Python 3.10–3.13 wheel 的 NumPy-only 安裝與既有箱形圖效能門檻；全部通過後才公開 GitHub Release，並將相同套件發布到 PyPI。
