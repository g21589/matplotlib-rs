# 0.0.6

本版延後建立箱形圖的 Python artists，並以 Rust 多執行緒繪製大量物件，降低建圖時間與記憶體用量。執行期仍只依賴 NumPy。

```bash
python -m pip install matplotlib-rs==0.0.6
```

## 更新內容

- `boxplot`／`bxp` 以批次儲存座標與樣式，第一次讀取時才建立對應的 `Line2D`／`PathPatch`；建立後仍可獨立修改或移除。
- Agg renderer 將大量連續的線段、patch 與箱形圖批次一起交給 Rust，平行點陣化與混色，維持原本的繪製順序。
- 重複的掃描列與相同樣式的 marker 共用運算結果。
- 規則浮點數箱形圖統計值保留為陣列；公開的 `cbook.boxplot_stats` 仍回傳一般的 dict list。
- 新增延遲建立、artist 讀取與修改、圖例、版面配置、輸出格式及多執行緒一致性的測試。

## 相容性與效能

- `MPLRS_LAZY=0` 可停用延遲建立；`MPLRS_THREADS` 可指定執行緒數。
- 不適用批次的自訂 transform、裁切或樣式沿用原本繪製路徑；SVG／PDF／PS 沿用各自 renderer。
- 已提交的本機量測中，5,400 箱的建圖與首次繪製合計比 0.0.5 快約 3.1 倍；50,000 箱快約 6.3 倍。數據依硬體與工作負載而異。
- 量測環境、逐輪資料、像素比對與限制見 [效能報告](../benchmarks/boxplots-lazy.md)。

發布流程會檢查版本一致性、完整 CI、Python 3.10–3.13 wheel 的 NumPy-only 安裝與既有箱形圖效能門檻；全部通過後才公開 GitHub Release，並將相同套件發布到 PyPI。
