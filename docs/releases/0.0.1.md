## 自有繪圖與輸出格式

共 **57 個繪圖案例**。PNG 比較 RGBA 像素，必須完全相同；
向量輸出固定 `SOURCE_DATE_EPOCH=0` 與 `svg.hashsalt`，
僅忽略 PostScript `%%Title:` 的輸出檔名行，其他內容必須完全相同。
另檢查兩側輸出檔名集合，沒有缺漏或多出的檔案。

| 格式 | 完全一致／總數 | 通過率 |
| --- | --- | --- |
| PNG | 69／69 張，涵蓋 57／57 案例 | 100% |
| SVG | 66／66 份 | 100% |
| PDF | 66／66 份 | 100% |
| EPS | 65／66 份 | 98.48% |
| 四種格式同時符合的案例 | 56／57 | 98.25% |

嚴格全格式比較的退出碼為 **1**，原因是 `polar_more.eps` 的裁切路徑快取定義及編號不同。
額外使用 Ghostscript **10.05.1**、`pngalpha`、`-r100 -dEPSCrop` 將兩份 EPS 轉為 PNG，
兩張圖像逐像素一致。這項補充檢查僅證實該檔案在此渲染設定下的結果；
原始 EPS 內容比較仍保留失敗結果。

## 效能測試

`tests/bench/phases.py` 建立 8 × 6 吋的 2 × 2 subplot：
每個 panel 有兩條各 1,000 點的曲線、20 個 scatter 點、標題、圖例、格線，並套用 tight layout。
第一次 PNG 存檔後，再更新標題並連續存檔 10 次。
每輪交錯執行 Matplotlib 與 matplotlib-rs，共各 5 個全新 Python 行程，列出各階段的最小值；
後續存檔欄位則是每個行程內 10 次存檔的平均，再取 5 個行程的最小值。
各階段最小值可能來自不同一輪，因此不把它們相加當成完整執行時間。
量測時沒有同時執行測試或編譯。

| 階段 | Matplotlib 最小值（ms） | matplotlib-rs 最小值（ms） | 倍率 |
| --- | --- | --- | --- |
| import | 588.7 | 329.0 | 1.79× |
| 建立圖表與 tight layout | 188.8 | 199.9 | 0.94× |
| 第一次 PNG 存檔 | 294.0 | 103.0 | 2.85× |
| 後續 PNG 存檔（每次） | 299.6 | 86.3 | 3.47× |

五輪數值有明顯波動，另列中位數供判讀；原始逐輪值保留在 `benchmark.log` 與 `benchmark.json`。

| 階段 | Matplotlib 五輪中位數（ms） | matplotlib-rs 五輪中位數（ms） |
| --- | --- | --- |
| import | 1223.2 | 553.4 |
| 建立圖表與 tight layout | 312.3 | 270.4 |
| 第一次 PNG 存檔 | 374.9 | 108.8 |
| 後續 PNG 存檔（每次） | 390.6 | 156.0 |

倍率為 Matplotlib 耗時／matplotlib-rs 耗時；大於 1 表示該階段 Rust 實作較快。
import 包含 NumPy 與 pyplot，後續存檔包含重新繪圖、PNG 壓縮及檔案寫入。
這是一個工作負載的量測，不保證所有圖形或完整程式均有相同比例的加速。

## 重跑方式

在專案根目錄及已啟用的 Python 虛擬環境執行：

```bash
python -m pip install 'maturin>=1.5,<2' 'matplotlib==3.11.2'
python -m pip install -e .
sh scripts/dev_build.sh --locked
export PYTHONPATH="$PWD/python"
export MPLBACKEND=Agg

# Linux：自動補上 PyO3 test executable 所需的 libpython linker flags。
sh scripts/test_rust.sh

for test in tests/unit/test_*.py tests/lowlevel/diff_*.py tests/model/first_plot.py; do
    python "$test" || exit 1
done

COMPARE_OUT=/tmp/mplrs-0.0.1-compare \
    COMPARE_VECTOR=svg,pdf,eps python tests/compare/compare.py

curl -fL https://codeload.github.com/matplotlib/matplotlib/tar.gz/refs/tags/v3.11.2 \
    -o /tmp/matplotlib-v3.11.2.tar.gz
tar -xzf /tmp/matplotlib-v3.11.2.tar.gz -C /tmp
GALLERY_OUT=/tmp/mplrs-0.0.1-gallery \
    python tests/gallery/run_gallery.py /tmp/matplotlib-3.11.2/galleries -j 2 --timeout 60

sh tests/bench/best_of.sh mpl 5
sh tests/bench/best_of.sh rs 5

# 本次發行量測以此順序交錯執行，並從各欄取五輪最小值。
for round in 1 2 3 4 5; do
    MATPLOTLIBRC=tests/mplrc python tests/bench/phases.py mpl
    MATPLOTLIBRC=tests/mplrc python tests/bench/phases.py rs
done
```

如參考實作因耗時而 timeout，可提高 `--timeout` 後重跑該案例；
互動範例仍需要另行提供其執行條件。Gallery 遇到 DIFF／ERR 會以非零退出碼結束，
沒有匹配腳本亦會報錯。測試腳本退出碼與結果內容都應納入判讀。
