# 0.0.2

本版改善大量箱形圖的物件建立時間，加入可重現的效能測試與 GitHub Actions CI／CD。

## 效能改善

相同的單張圖包含 30 組、每組 180 個隨機箱形圖，每箱 100 個樣本、各組不同顏色。
保留 5,400 個可獨立修改的箱體與 32,400 條線，未合併物件或延後建立至繪製階段。

在相同 Python 3.12／NumPy 2.3.5 環境，原始 0.0.1 wheel 與本版各預熱一次、交錯量測五次：

| 指標（五輪中位數） | 0.0.1 | 0.0.2 | 改善 |
| --- | --- | --- | --- |
| 建圖 | 36.601 秒 | 1.458 秒 | **25.10×** |
| 建圖＋首次繪製 | 37.047 秒 | 1.779 秒 | **20.83×** |
| 行程最高 RSS | 593.6 MiB | 266.9 MiB | 減少 55.0% |

五輪個別建圖倍率為 12.47、24.50、25.10、15.47、26.21；全部超過 10 倍。
所有暖機與量測的資料及 RGBA hash 相同，存檔 PNG 差異像素為 0。
這是指定負載與本機環境的量測，並不代表所有圖表都加速 25 倍。

改善包括規則浮點矩陣的批次 boxplot 統計、共用樣式驗證、原生物件複製、
座標範圍批次更新與延遲配置 callback 儲存空間。
需要自訂 Axes、座標轉換、單位或特殊樣式時保留一般路徑。
新增物件獨立性、修改、移除、callback、pickle、property cycle 與統計精確比較測試。

[完整重跑方式](../../tests/bench/README.md) · [五輪原始數據](../benchmarks/boxplots-0.0.2.json)

## 本機驗證

- Rust：1 個單元測試通過；doctest 0 個。
- Python：4 支單元測試、4 支底層 renderer／字型差異測試、1 支原生模型案例全通過。
- Boxplot：186 組統計比較，以及 19 組物件行為與像素案例通過。
- 自有繪圖：58 個案例，PNG 74／74、SVG 71／71、PDF 71／71 完全一致。
- EPS：70／71 內容一致；既有 `polar_more.eps` 快取定義差異仍保留，Ghostscript 轉圖後像素一致。
- 官方 boxplot gallery：6／6 像素一致；未重跑全部上游 gallery。

完整 0.0.1 gallery 範圍與相容性限制見 [前版驗證報告](0.0.1.md)。
功能案例通過率與原始碼行／分支覆蓋率不同，本版未量測原始碼覆蓋率。

## CI／CD 與安裝

新增 push／PR 的 Python 3.11～3.13 自動測試，以及版本標籤觸發的發布流程。
發布前必須通過全部 CI、乾淨環境 wheel 安裝驗證、5,400 個箱形圖像素一致及至少 10× 建圖效能門檻。
詳見 [CI／CD 說明](../CI.md)。

Release 附件包括 CPython 3.11／3.12／3.13、Linux x86_64、glibc 2.28 以上的 wheel，
source distribution、Actions 效能原始紀錄及 `SHA256SUMS`。
下載符合 Python 版本的 wheel 後：

```bash
python -m pip install /path/to/matplotlib_rs-0.0.2-*.whl
```

其他平台可從原始碼編譯，但尚未驗證。本版不發布至 PyPI。
distribution 版本為 `0.0.2`；`matplotlib_rs.__version__` 保留相容性 API 版本 `3.11.2`。
