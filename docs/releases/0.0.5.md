# 0.0.5

本版將影像檔讀寫移至 Rust 核心，並加入平行 PNG 編碼。執行時依賴仍只有 NumPy；即使已安裝 Pillow，也不會匯入它。

```bash
python -m pip install matplotlib-rs==0.0.5
```

## 更新內容

- `savefig`、`imsave`、`imread`、`AxesImage.write_png` 及 SVG／PDF／PGF 內嵌影像改由 Rust 處理。
- PNG 使用平行過濾與 zlib 壓縮，支援 `pnginfo`、ICC profile 與 EXIF；輸出不隨執行緒數改變。`MPLRS_THREADS` 可指定執行緒數。
- Rust 核心支援 JPEG、TIFF、WebP、GIF 讀寫及 AVIF 寫入；`PillowWriter` 支援 GIF、APNG 與動態 WebP。
- 移除 `full` extra 的 Pillow 依賴；fontTools 與 ContourPy 仍為選用依賴。
- 不支援的 `pil_kwargs` 會回報 `ValueError` 並列出支援的參數。

## 相容性與限制

- AVIF 不支援讀取；調色盤 TIFF 不支援讀取。
- JPEG 與 AVIF 使用不同於 Pillow 的編解碼器，輸出不保證逐像素或逐位元組相同。
- SVG／PDF 內嵌影像的壓縮位元組可能不同；既有 CI 會解碼影像比較像素，並比較其餘內容。
- 支援格式、參數與效能數據見 [README 的影像檔說明](../../README.md#影像檔)。

發布流程會驗證版本一致性、Python 3.10–3.13 wheel 安裝、NumPy-only 環境、完整 CI 與既有箱形圖效能門檻；全部通過後才建立 GitHub Release 並發布 PyPI。
